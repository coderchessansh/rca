# Rebel Cube Association website

A responsive static website for the Rebel Cube Association (RCA).

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — scramble generator and practice stopwatch
- `assets/rca-mark.jpg` — supplied RCA logo

## Run locally
Open `index.html` in a browser.

## GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Competition dates, registration links and leaderboard results are intentionally left unpublished until confirmed.
